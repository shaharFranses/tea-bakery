# Controls (source for portal copy; keep in sync with the build; SPEC v1.0 §11 controls copy)

Tap/click a cell to set an empty mold, tap again to place a cake, tap again to clear. Right-click sets or clears an empty mold (desktop). Undo, Hint and Reset are below the tray on phones and beside it on desktop.

| Action | Touch | Mouse | Keyboard |
|---|---|---|---|
| Cycle a cell: empty → empty mold → cake → empty | tap | left click | — |
| Set or clear an empty mold | — | right-click | — |
| Settings "Tap order: cake first": empty → cake → empty mold → empty | tap the Tap order button | click | — |
| Auto-molds on/off (default on) | tap the Auto-molds button | click | — |
| Skip the PKD intro | tap | click | any key |

Day-0 skeleton note (not portal copy): Undo, Hint and Reset are not built yet; the skeleton has "New tray", "Clear", size buttons and a Sound toggle.
