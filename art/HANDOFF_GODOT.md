## Per-cell draw order and sizes (pitch = cell size in px; all centred in the cell)
1. **Tile:** a rect of `pitch × (1 − 0.075)`, inset by `0.0375 × pitch` per side. The gap shows the tray lining.
2. **Region joins** (code-drawn, no sprite): between two same-region neighbours, fill the gap with the region's **seam** colour. Draw the region's outer edge as a soft rim about `0.06 × pitch` wide in the **rim** colour (StyleBoxFlat border or a polyline). Never use ink or black lines. The gap between different regions shows the **tray lining #FFF8EC**, inside a pewter #A8A09F tray rim.
3. Under-layer: `overlay_solved` / `overlay_conflict` / `given_plate`, each the size of the tile rect.
4. **Cake:** `cake_berry` drawn at **1.0 × pitch** (the disc is about 74% of the cell and the halo reaches about 83%, which is the spec's "~80%"), offset down by `0.02 × pitch`.
   **Mold:** drawn at **0.70 × pitch** (the visible tin is about 60% of the cell, per §10). `board_view.gd` currently uses 0.6 × pitch, which shows only about 51%, so please use 0.70.
5. Over-layer: `badge_conflict` / `badge_solved`, each the size of the tile rect. Conflict also keeps the 2 px shake (spec §8).

## Import settings (Godot 4.3, web)
- Texture import: **Compress mode = Lossless**. Avoid VRAM compression because it causes artefacts on flat pastels and alpha edges in the web build. Turn **Mipmaps/Generate = ON**, because the sprites are drawn 2–5× smaller than the source. Turn **Process/Fix Alpha Border = ON** and leave Premultiplied Alpha OFF.
- Filter: on the BoardView, set `texture_filter = TEXTURE_FILTER_LINEAR_WITH_MIPMAPS` (or make it the project default). Do not use Nearest.
- **Which size to load:** Godot does not pick `@2x` automatically. Recommendation: **load only the `@2x` files** and let mipmaps downscale them. Cells reach about 215 device px on a DPR-3 phone and 152 CSS px on a 1280×800 desktop. The 1x files are a fallback if the pck budget gets tight. If you only ship `@2x`, exclude `*.png` without `@2x` via the export filter.
- **Size:** @2x set = 624 KB on disk as PNG; both sets = 940 KB. Board art for the ≤20 MB budget is under 0.7 MB.
- The `.gdignore` on `art/` stays: it covers the proposal and mock files only. `assets/board/` is not ignored.

## Notes / asks
- **Conflict look:** D-10 says "dashed berry outline + ! badge + soft tint" and §10 says "cherry ring + diagonal hatch + ! badge". The overlay does both: a dashed cherry ring plus a hatch, with the badge on top. Unit tinting (the shared row, column or region) is a P1 overlay.
- `mold.png` replaces the code-drawn placeholder in `board_view.gd` (`MOLD_SPRITE`) automatically. The cake has no sprite hook yet, so Build needs to add one for `res://assets/board/cake_berry@2x.png`.
